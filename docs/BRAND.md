# Lockwork — Brand (decided 2026-09-26)

**Public name:** Lockwork · **Runner-up:** HireProof · **Internal:** Contest OS / `contest_os`

## Reads

1. **Primary — Lock + Work:** Escrow purse locked until one winner is paid; bid = ship the work.
2. **Secondary — clockwork (soft-lean):** Reliability dual-read (“runs like clockwork”). Never the hero metaphor.

## Lines

- **Primary:** Lock the payout. Ship the work. Hire the winner.
- **Secondary:** Lockwork — the hire that runs like clockwork, because the payout was locked.

## Logo

- Primary mark: **padlock** or **sealed purse**
- Secondary texture only: gear tooth — **never gears without a lock**

## Money / fee copy

Escrow-primary always. No “clockwork fees.”
