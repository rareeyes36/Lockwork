# Lockwork — One-pager

**Lock the payout. Ship the work. Hire the winner.**

Contest-to-hire clearinghouse: employer locks a sealed purse (custodial and/or Base USDC) → workers compete by shipping the work → **one winner is paid and hired** onto a company seat. Not hours. Not unpaid contests.

## Economics (live)

| Knob | Value |
|------|--------|
| Platform fee | **250 bps** only on outward release to the winner |
| Sponsor placement | **500 bps** on the sponsor slice (not the full purse) |
| Company seat | **$79/mo** after hire |
| Nesting depth | ≤ 3 |

IP: unselected submissions stay with the worker. Assignment tracks **paid + seat** only.
