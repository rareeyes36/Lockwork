Lockwork

Deploy the escrow contract

One transaction from your own wallet. It deploys LockworkEscrow on the test network with Circle's test USDC. The fee is 2.5% on release, paid to your wallet. Nobody, including you as deployer, can move locked funds except the employer who locked them.

Before you start

testnet · no real money
  1. Install MetaMask or Coinbase Wallet (or open this page inside the wallet app).
  2. Get free Base Sepolia ETH for gas: Coinbase faucet (or any Base Sepolia faucet).
  3. Get free test USDC for locking jobs: faucet.circle.com → Base Sepolia.
